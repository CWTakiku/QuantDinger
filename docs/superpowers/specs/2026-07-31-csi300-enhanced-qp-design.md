# 沪深300指增：日频 Alpha + 周频 QP 两层调仓设计

> 日期：2026-07-31  
> 状态：待实现（规格已确认）  
> 数据源：Tushare  
> 执行形态：回测 / 信号优先；实盘算法拆单二期

## 1. 目标

在 QuantDinger 上落地一套贴近头部私募习惯的 **沪深300指数增强** 流水线：

- **日频**：股票池过滤、因子预处理、Alpha 预测更新、风险/偏离监控  
- **周频**：二次规划（QP）求解目标权重并主调仓  
- **日频微调**：仅在偏离/风险/流动性触发时局部再平衡  
- **基准**：`CNStock:000300.SH`；宇宙：`pool=csi300`  
- **方向**：long_only；遵守 A 股整手规则（普通 100 / 科创开仓 200）

非目标（本期不做）：完整商用 Barra 授权模型替换、实盘 SOR/算法拆单、用 ML 完全替代线性 Alpha。

## 2. 完整流水线

### Step1 股票池预处理（日频）

1. 基础池：沪深300 **当期**成分（point-in-time，禁止未来成分）。  
2. 过滤：
   - 停牌、涨跌停（不可买入侧）  
   - 流动性异常（成交额/换手突变、连续异常）  
   - 最低日均成交额门槛（可配，默认近20日日均成交额下限）  
   - ST / 上市不足 60 个交易日  
3. 输出：当日可交易集合 \(U_t\)。

### Step2 因子预处理（日频，重中之重）

对每个因子截面：

1. MAD / Winsor 去极值（默认 1%–99% 或 5×MAD）  
2. 截面 Z-score  
3. **行业中性 + 市值中性**（沪深300标配；回归残差作法）  
4. 缺失：层内截面中位数填充；缺失率过高则当日该因子失效  

刷新规则：

| 类型 | 刷新 |
|------|------|
| 量价、波动、流动性、北向、融资 | 每个交易日 |
| 基本面 / 部分估值 | 财报或指标更新日刷新，其余交易日 **沿用** |
| 一致预期 | 日度（按 Tushare 权限接口可得字段） |

### Step3 因子合成 Alpha（日频）

**主路径：线性（必做）**

- **基线**：中性化后因子等权合成 \(\alpha\)（抗过拟合，实盘基线）  
- **进阶（可开关）**：
  - 滚动 ICIR 加权；或  
  - L2 正则线性回归，label = **未来 5 个交易日相对基准超额**（适配周频调仓）

**辅路径：机器学习（二期）**

- LightGBM / FFN 预测未来超额，仅作辅助 Alpha 或残差增强  
- 沪深300非线性增量有限，**不得**在 MVP 完全替代线性模型  

因子分层与初值权重（可配置）：

| 层 | 权重 | 优先因子 |
|----|------|----------|
| 资金流 | 25% | 北向 1D/5D/20D、融资 5D 变动、融资/流通市值 |
| 一致预期 | 20% | EPS/NP 1M 上修、Forward_EP、目标价空间、上修家数、连续上修动量 |
| 估值质量 | 20% | EP/BP/SP/CFP、ROE/ROA、毛净利率、同比成长 |
| 动量 | 20% | Ret_60/120、RelRet_20、MA60_Dev、HighLow_20（Ret_5/10 默认关闭） |
| 风险流动性 | 15% | 低 Vol_20、DownsideVol、Beta、Turnover/Amount、Amihud |

### Step4 组合优化（周频主执行）

每周收盘后（或下周开盘前信号）求解目标权重 \(w^\*\)。

目标函数：

\[
\max\ \alpha^\top(w-w_b)
-\lambda(w-w_b)^\top\Sigma(w-w_b)
-\gamma\cdot\mathrm{Turnover}(w,w_{\mathrm{prev}})
\]

其中：

- \(w_b\)：沪深300成分 point-in-time 权重  
- \(\Sigma\)：简化风格风险模型（风格因子协方差 + 特异方差）；不用原始收益样本协方差作为主力  
- \(\lambda,\gamma\)：可配  

硬约束（初值，可配）：

| 约束 | 初值 |
|------|------|
| 满仓、禁止做空 | \(\sum w_i=1,\ w_i\ge0\)；\(i\notin U_t\Rightarrow w_i=0\) |
| 单票主动权重 | \(\lvert w_i-w_{b,i}\rvert\le 2.5\%\) |
| 行业主动偏离 | 单行业 \(\le5\%\) |
| 风格暴露 | 市值/价值/盈利/波动相对基准带宽（如 0.3–0.5σ） |
| 跟踪误差 | 年化主动风险上限 4%（区间 3.5%–5%，MVP 可先监控后硬化） |

**日频**：不跑全量 QP；仅监控持仓偏离、风险突破、流动性预警；触发则 **局部**再优化（冻结大部分权重）。

### Step5 交易执行层

- 回测/信号：按目标权重生成订单意图；应用整手规则与成本/滑点  
- **换手阈值**：若 \(\sum\lvert w^\*-w_{\mathrm{hold}}\rvert/2\) 低于阈值（可配），**放弃调仓**  
- 实盘算法拆单、冲击成本控制：二期  

## 3. 两层优化时序

```text
每个交易日收盘后
  Step1 池过滤 → Step2 因子 → Step3 α
  监控：偏离 / TE / 流动性
  if 触发微调阈值:
      局部 QP（冻结大部分持仓）→ 小额调仓（仍受换手阈值约束）

每周主窗口（默认周一）
  全量 QP → w*
  if 换手 ≥ 阈值:
      批量调仓至 w*（整手、成本）
  else:
      跳过
```

## 6. MVP vs 二期

### MVP（本期）

1. Step1–3：过滤 + 中性化 + **等权线性 Alpha**（ICIR 开关可选）  
2. Step4：满仓/多头/单票主动/行业偏离/换手惩罚 + 简化风格 Σ  
3. Step5：回测阈值跳过 + 整手 + 佣金滑点  
4. 示例策略源码 + 回测可跑通 CSI300  

### 二期

- L2 回归 T+5、LightGBM 辅助 Alpha  
- 更完整风格风险 / TE 硬约束  
- 一致预期全字段（视 Tushare 权限）  
- 实盘算法拆单与冲击模型  

## 7. 验收标准

1. 日终任务可产出中性化因子与 \(\alpha\) 截面（覆盖率、缺失率可观测）  
2. 周频 QP 在约束下有可行解；不可行时有明确降级与日志  
3. 回测相对 `000300.SH` 输出超额、换手、主动权重/行业偏离统计  
4. 低于换手阈值的周次不产生无效调仓  
5. 小资金触发整手拒单时有诊断（与现有 `minimum_trade_unit` 一致）  

## 8. 风险与依赖

- Tushare 积分/权限不足会导致一致预期或北向字段缺口 → 该层权重自动再分配或跳过  
- 简化 Σ 与真实 Barra 有差距 → TE 约束 MVP 以监控为主  
- 日频全宇宙算力：需批量向量化 + 缓存，避免策略进程内重算全历史  

## 9. 已确认决策摘要

- 数据源：Tushare  
- 节奏：日频算分 + 周频主调仓 + 日频阈值微调  
- 建仓：指增 QP（非 Top-N 等权）  
- Alpha：线性为主，ML 为辅（二期）  
- 流水线：Step1–5 如上
